# A5 双面答题卡与识别接入

## 工作流

在班级或学生库点击学生姓名，查看二维码并下载 A5 双面 PDF。班级页支持默认卡片批量下载；考试页按选择题和文字题数量自动增加页数。每名学生的页面身份固定，重印不会轮换二维码；显式重发学生二维码会撤销旧卡。

正面每页 40 道单选题，背面每页 10 道文字题。纸张为 148 × 210 mm。选择框为矩形，文字框按文字题顺序编号；前后两面均有右上角二维码及四角定位点。A5 纸双面打印选择 100% 实际大小、长边翻页。A4 拼版须保证每个 A5 页面按实际尺寸输出，扫描时一次完整拍摄一页。

新建考试可输入连续选择题答案、逐题分值，以及每行一道的文字标准答案。扫描器选择对应考试后上传页面；主后台按本场题型顺序把卡片题位映射到考试题号。识别服务只返回读到的内容和置信度，不接收标准答案、不做判分或纠错。

老师结束考试只结束课堂作答，`ACTIVE` 和 `CLOSED` 都允许扫描。`DRAFT` 与 `ARCHIVED` 不接受扫描。二维码仍必须属于机构及该场考试快照名单，教师仍受班级权限限制。

## 持久化与复核

- `/api/v1/students/{id}/answer-card`：稳定的二维码预览。
- `/api/v1/students/{id}/answer-sheet.pdf`：单生下载，可传 `choice_pages` 和 `text_pages`。
- `/api/v1/classes/{id}/answer-sheets.pdf`：全班默认双面卡。
- `/api/v1/sessions/{id}/answer-sheets.pdf`：本场快照名单及完整页数。
- `/api/v1/sessions/{id}/scans`：识别原文、题位映射、状态。
- `/api/v1/scans/{id}/image`：经权限校验的原图。
- `/api/v1/scans/{id}/review`：核验本页全部答案并重新计分。
- `/api/v1/scans/{id}/retry`：失败或待复核记录重新进入队列。

页面令牌为带 HMAC 的不透明二维码记录标识、页型和页码；不含姓名或学生编号。`QR_SIGNING_SECRET` 必须持久保留。后台识别消费者单实例运行，读取数据库中 `PROCESSING` 记录，崩溃后可继续；失败可重试。同一 `client_capture_id` 重传仍返回原回执。

正反面按题合并，不整份覆盖。原图与识别原始响应保存到 `SCAN_STORAGE_DIR`，复核内容另附审核人、时间和答案；原始文本不被替换。OCR 及低置信度答案复核前不计入已确认得分。当前文字题采用去首尾空白后精确匹配，不提供语义判分。

部署采用独立的 `127.0.0.1:8092` Recognition Service 和 `classroom-assessment-recognition-worker.service`。扫描文件存放在发布目录外的 `/opt/classroom-assessment-platform/data/scans`。浏览器每五秒检查扫描状态变化并更新成绩；识别进程与 API 的内存事件总线并不跨进程共享。

## 本轮证据与限制

本地六项后台回归、数据库迁移/漂移检查、Web 构建通过。浏览器已验证二维码弹窗、文字题批量输入、原图核验及得分刷新。实际 PDF 渲染后，40 道合成实心涂框和 10 个印刷英文词通过真实识别引擎验证。

线上完整 HTTP 验收由 `Invoke-ClassroomIntegration.ps1 -Action Verify` 执行，结果以验收报告为准。该脚本仅在既有演示机构创建合成测试班级/学生/考试，不修改账号密码，完成后归档测试记录。

真实纸张打印、手写样本以及新版安卓实拍仍须单独验收；不得把合成图片、旧版真机测试或签名构建写成新版全链路真机通过。
